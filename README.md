# GROMACS 参数填写助手

中文、离线可用的个人填表辅助工具，面向 GROMACS 2018.8 中常见的经典固定拓扑模型。

**在线使用：<https://adrcyf.github.io/gromacs-input-helper/>**

也可以下载 `index.html`，双击后离线使用。没有服务器端处理，不上传导入文件，不保存填写记录；刷新或关闭页面后清空。

## 使用

1. 从左侧目录选择文件。
2. 手动填写，或选择已有文件／粘贴文本后导入。
3. 悬停 ⓘ 查看简释，点击展开详细说明。核对导入摘要中的未处理项。
4. 点击“生成内容”，复制到文本编辑器，保存为对应扩展名。

覆盖力场规则、原子类型、分子定义、体系拓扑、GRO 坐标以及 EM/NVT/NPT/生产采样 MDP。常用方法预选，数值不自动填写；零和负电荷是有效输入。

## 导入范围

- MDP：识别已有表单字段，兼容横线／下划线；重复参数采用最后值并提醒。不强行区分 NVT 与生产采样。
- ITP/TOP：按区块内容识别，支持常见可选原子类型列、单分子定义及现有相互作用区块。完整力场内的原子类型可同时回填。
- GRO：保留支持的精度、速度与 3／9 分量盒子，自动统计位点数。
- `#include` 只记录路径，不加载外部文件。条件分支、多个分子定义、宏表达式和不支持的函数会提示，不进行完整预处理。
- 导入允许缺项，但生成前仍需填写该文件必要的数据。未知选项保留显示并提醒；生成只包含映射到表单的字段，不是原文件的无损编辑器。

本工具不生成或拟合力场，不自动猜电荷、不自动补辅助质量点，不启动模拟。参数来源与配套关系需要自行核实，并用实际 GROMACS 检查。

## 开发

`src/` 保存独立模块。修改后运行：

```console
python build.py
```

生成的 `index.html` 自包含，不依赖 CDN、框架或在线字体，可直接作为 GitHub Pages 静态入口。浏览器检查可使用 `tests/test_browser.py`；需要 Python Playwright 和可用 Chromium 浏览器，应用本身不需要这些依赖。

格式与方法依据：[GROMACS 2018.8 MDP文档](https://manual.gromacs.org/documentation/2018.8/user-guide/mdp-options.html)、[同版手册](https://manual.gromacs.org/documentation/2018.8/manual-2018.8.pdf)。工具代码独立编写，未拷贝第三方生成器代码。
